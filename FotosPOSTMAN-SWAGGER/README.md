# Entendendo as imagens do projeto

Abaixo estão as imagens da pasta FotosPOSTMAN-SWAGGER, demonstrando o funcionamento de cada etapa:

## Banco de Dados Local
- **Banco-de-dados-Xampp.jpeg**: Demonstra a listagem de registros e criação das tabelas no MySQL integrado via XAMPP.

## Operações de Turma
- **Turma-PostClasses.jpeg**: Demonstra o cadastro de uma nova Turma (POST) documentado no Swagger.
- **Turma-ListClasses.jpeg**: Demonstra a listagem geral das turmas cadastradas (GET).

## Operações de Aluno
- **Aluno-Post-Aluno.jpeg**: Demonstra a criação de um Aluno matriculado a uma turma (POST) via Swagger.
- **Aluno-PostAluno@faculdade.edu.jpeg**: Demonstra o teste validando as regras de negócio de e-mail limitadas ao domínio `@faculdade.edu` no cadastro.
- **Aluno-ListaAluno.jpeg**: Traz todos os alunos já criados listados em uma chamada GET genérica de listar.
- **Aluno-GetAluno-1.jpeg**: Traz as informações de um determinado Aluno baseado em uma busca com identificador ID = 1.
